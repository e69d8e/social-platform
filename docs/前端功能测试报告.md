## 一、发现并修复的 Bug

### 🔴 BUG-01：滑块验证码图片渲染失败，登录被阻断（已修复）

| 项 | 内容 |
|---|---|
| 严重级别 | P0（阻断登录） |
| 现象 | 登录页验证码区域全白。两张 `<img>` 的 src 变成 `http://127.0.0.1:8080/iVBORw0KGgo...`——后端返回的裸 base64 被浏览器当作相对 URL 发起了 GET（返回 414 URI Too Large），`naturalWidth=0` |
| 根因 | `SlideVerify.vue` 重构时直接 `:src="bgImage"`，未拼接 `data:image/png;base64,` 前缀 |
| 修复 | src 改为 `'data:image/png;base64,' + bgImage`，重新构建部署 |
| 复测 | 背景图 310×155、拼图块 65×65 正常渲染；截图 `B0-captcha-broken.png`（修复前）→ `B1-captcha-rendered.png`（修复后） |
| 经验 | 该 Bug 无法被编译/npm build 发现，只有真实浏览器 E2E 才能暴露——本次测试的核心价值之一 |
